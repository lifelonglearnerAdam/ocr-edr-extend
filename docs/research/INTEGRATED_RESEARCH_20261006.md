# 五个方向的统一研究设计

2026-10-06。工作假设，不是已确认的新方法或论文结论。项目：`optimization/ocr-edr-team`。

## 核心问题与贡献边界

目标是在多个 OCR 解析器的公式与表格输出上，用不超过 3B 参数的学生提出有依据的修改，同时控制错误接受、原本正确输入的退化和交互成本。五个方向不是五篇结果拼接：公式/表格是任务，蒸馏提供提议能力，独立验收负责选择，Agentic RL 分配编辑/重渲染/停止预算，解析器留出验证分布迁移。

已有 OCR-EDR、LATTE、DEC 等工作覆盖渲染反馈、迭代、局部修改、验收、保持、训练和迁移的很多组合，见[现有一手文献检查](PRIOR_ART_20261003.md)。不能把这些组件或它们的排列称作创新。待验证的具体切入点是：**在相同模型和预算下，通过提议—验收的独立学习及局部证据冲突处理，改善修复收益、误改风险和成本之间的前沿；该改善能否在未知解析器上保留？** 若强基线已达到同样前沿，调整机制或接受该假设不成立。

## 一个系统中的五个角色

| 原想法 | 系统角色 | 需要单独成立的证据 |
|---|---|---|
| H1 公式/表格专项 | 结构化输出和编辑器；公式 token/树结构、表格 cell/row/span | 各模态完整样本的净改善及 Good 保持，不能只报可渲染率 |
| H4 蒸馏/小模型 | 学生 proposer；直接目标 SFT，再比较受验证教师轨迹 SFT | 同学生、同训练源、同训练预算下的提议质量差异 |
| H3 Jev/级联 | 独立 accept/reject/escalate；当前为结构化证据上的文本路由，视觉模块另计 | 原始候选与证据固定时的覆盖率、错误接受、漏拒绝和完整成本；置信度必须校准 |
| H2 Agentic RL | 学习何时编辑、申请渲染、升级或停止 | 同 SFT 初始化、训练数据、候选/交互预算下 RL 的增量；独立 reward 审计 |
| H5 多解析器普适性 | 留出 parser 与来源分组的评测协议 | 已知和未知 parser 的完整输入、逐系统风险/成本；不可按 Bad 选择测试集 |

推理输入为源图、初始/当前 OCR、当前渲染及可追溯的编辑历史。参考标注、Good/Bad 真值、教师答案和官方分数只用于离线训练/评估，不能进入部署策略或验收提示。候选生成与候选接受的损失、模型版本和训练来源分别记录。验收模型不可简单复用 proposer 的自评分当作独立证据。

**接口修正（10月6日一手文档核查）：** `jev-1.13.0`仅接受文本/结构化文本，不能直接读取图片。视觉比较需要独立模块，Jev只在其可追溯证据上做决策/路由；完整计入证据生成成本，并与相同证据上的简单规则比较。Choice confidence为经选项数归一化的pmax统计量，不能当原始pmax或校准正确率。见[Jev接口核查](JEV_INTERFACE_CHECK_20261006.md)。这一事实改变实现，不撤销H3的待验证角色。

## 个人研究取舍：局部证据而不是整体自信

1. **候选产生与决策分开报。** 对固定候选记录潜在可修复数（离线 oracle 只作上限）、真实接受的修复、被拒绝的好候选、被接受的坏候选。全拒绝保留不能算优质纠错。
2. **验证编辑支持范围。** 格式合法只证明可执行。公式检查被改变的符号/上下标/界限；表格把 cell 地址、邻接/跨度与源区域绑定。允许正确修复改变行数或 span，但对未编辑区域检查保持；不能把所有拓扑变化都当错。
3. **遇到证据冲突会停/升级。** 语法、结构、源图和不同 judge 产生冲突时，廉价高置信分数不得直接覆盖冲突。校准分数不是 correctness certificate；规则也不能保证视觉正确。
4. **重渲染作为可付费的信息动作。** RL 要学习某次重渲染是否值得，而非每轮机械调用。比较固定渲染数的调度、随机调度和学习调度，核验真正更新后的 evidence hash；stale 条件只能作受控实验，不突破部署验收约束。
5. **从风险—收益—成本曲线选择。** 多个保持惩罚、验收阈值和预算展示 Pareto 前沿，不事后挑单个最高分。未达到预先设定退化约束的配置可以标为不可部署，但保留完整结果。

训练效用可写为

\[
U=\Delta Q-\lambda_{\mathrm{reg}}\mathbf{1}[G_0\land\neg G_T]
 -\lambda_{\mathrm{fa}}\mathbf{1}[\text{accept harmful proposal}]
 -c_e N_e-c_r N_r-c_j N_j-c_t N_{\mathrm{tokens}}.
\]

这里 Q 是离线参考/源审计分数，G 是**明确定义**的 Good 标签。CDM/TEDS 代理 Good 与源审计 Good 分开记，不能默认为一致。正负 reward 都做量纲/尺度审计；false-accept/regression 项可能重叠，单独消融避免重复惩罚伪造贡献。部署时没有 Q/G 真值。首先用有限的一步 SFT/保持对照建立提议基线，不能立即把上式当已验证 GRPO 奖励。

## 数据、校准与统计

现有公式 train128/dev32 只支持开发筛查；开发源已被查看，不能成为 untouched test。UniMER 包缺原始文档 ID，因此仅可报告图像/公式分组隔离和已执行去重。表格需要独立来源的 train/dev，不能复用检查过的四个 demo 页面训练；该 demo 的未知 parser 不能用于具名迁移主表。

正式数据角色为 train、model-dev、gate-calibration、locked-evaluation。模型/阈值选择、验收校准和最终检验的源组分别隔离，测试不因 parser 输出而筛选。校准集按 parser 和模态分层；parser A 参与训练/选择，parser B 完全留出，轮换 leave-one-parser-out 时重新独立训练和选择，不能只交换表头。

风险约束先用开发阶段描述性曲线，后用独立校准/评测。不在 32 个源上声称 1% 风险保证：即便零次坏接受，单侧 95% 精确二项上界为 \(1-0.05^{1/n}\)，n=32 约 8.94%；零错误时至少 n=299 个独立观察才能使该上界小于 1%。同源多变体、阈值搜索和 parser shift 都会影响保证条件；多个阈值试探不得复用朴素单阈值置信区间。无法满足独立性时仅报告经验曲线和不确定性。

统计单位优先原始页面/文档；仅有源图 ID 的数据按源图分组，并声明边界。用配对 group bootstrap 报均值差的区间，分开绘制 Good 风险与 Bad 收益；先保证覆盖和保留失败项，再讨论显著性。一次 seed 的筛查不能支持稳健训练结论；有信号后至少三个预定 seed，不能只保留最好者。多假设、多指标筛选产生探索结果，独立锁定评测才支持确认结论。

## 分层消融，不做混淆的全排列

| 层 | 固定项 | 因子与对照 | 拟回答的问题 |
|---|---|---|---|
| P 提议能力 | 学生、源图分组、输出协议、推理预算 | unchanged；zero-shot；直接 SFT；去显式保持对；annotation-only/native-error；较强教师独立 upper comparator | 是否真的增加有用候选，保持来自学习还是拒绝？ |
| D 蒸馏 | 学生、train源、教师版本、训练 token预算 | 发布标注直接目标；教师直接答案；教师 edit/render/stop 轨迹；轨迹打乱/去过程项 | 过程信息是否比多数据/更强答案有额外贡献？ |
| E 视觉/动作 | 固定 proposer checkpoint 和输入 | source-only；source+render；fresh/stale；局部patch/global rewrite；固定预算/学习调度 | 哪种证据和动作对净改善有因果支持？ |
| V 验收 | **相同候选池及其生成成本** | always-accept；syntax-only；独立VLM；Jev-only；Jev+结构；Jev+结构+escalation；oracle上界 | 闸门选择质量、冲突处理与升级是否值得？ |
| R 学习控制 | 同 SFT 初始权重、源组、工具、交互上限 | SFT继续相同步数；GRPO；去Good分支；去成本项；metric-only reward；固定渲染调度 | 策略增量还是额外训练/算力？ reward是否被钻空子？ |
| T 迁移/规模 | 冻结 pipeline、阈值和 budgets | seen/held-out parser；formula/table；2B/更大模型；相同样本不同错误 | 机制对未知错误分布、模态和容量是否稳定？ |

现有 A0–A10 草案只是组件蓝图；用上述因子拆解，每次 contrast 清楚写出同时改变的项。不要以 A5>A2 同时更改验收、循环次数、token 后单独归因 Jev。固定候选池的验收实验与整系统在线实验是两张表。图片数量改变实际 tokens，记录费用并补同成本设置，不假称绝对相同预算。

## 推进顺序和停止条件

1. 当前可运行：公式 source-only direct SFT 与去显式保持对的 192-step 对照，各 768 次样例暴露、每源六次。384 条完整数据循环2次；256条去keep数据循环3次。相同 seed/LoRA/优化器/步骤、不同目标分布与真实token必须报告。这个对照保留原生正确样例，不等于去掉所有 Good。
2. 对固定 96 个 dev 输入做同机器的 base/SFT/no-explicit-keep 推断。全部三种输入分别报，严格输出适配、raw/accepted区分；离线 CDM 与源审计分开，保存失败/截断。此阶段不加 GT 驱动的在线门，不做 checkpoint 搜索。
3. 有提议信号后，准备未使用的模型验证/闸门校准/留出数据和第二已知 parser；并行补表格训练和合法局部编辑空间。若无净改善，报告并先解决能力/标签问题，而非扩大 RL。
4. Jev/API/教师的版本、视觉接口、访问和实际费用先实测；额度或条款不确定则保留可替換独立 judge 接口，不伪造实验。不能用其他 judge 替换后仍叫 Jev 消融。
5. 有功能性 SFT 提议与审计过的验收标签后再做 D/V/E，再做 R；保持五方向目标，但不以阶段完成替代最终效果。

进展验证：每项协议有输入/源码/模型/环境/hash、完整结果、覆盖和失败检查；训练 dev不进入优化器；外部发布按用户授权另执行。达到更好风险—收益—成本前沿、通过未知parser及两模态评估、相关工作比较和独立统计验证之前，这个整体研究目标保持未完成。

## 10月7日原生表格证据对设计的约束

[完整原生表格诊断](NATIVE_TABLE_RESULTS_20261007.md)补充了可执行约束：坐标约定必须先验证，不能以集成故障制造弱基线；JSON示例可使基座103例全部合法但全stop，格式成功不能替代修复。原生parser的OCR置信度向量在坐标异常/修正两条件完全相同，而文字关联质量明显不同；H3必须保留几何/源图证据及同证据规则对照。

官方HTMLnormalizer可掩盖raw rendering中的字面格式标签，TEDS-S分母也会受单元格内格式节点影响。H2的metric-only reward、H4的保持标签及教师轨迹必须审计这种代理与视觉目标的差别。H1/H2动作对照需要说明插入/删除cell、inline公式格式和全局重写的可达性；若所需状态不在动作空间中，RL不能凭学习补出未实现的动作。H5继续要求明确parser及预训练来源：当前PubTabNet公开train源的开发诊断不证明未见来源迁移。

这些观察决定后续消融顺序和失败解释，不构成新颖性或最终方法收益的证明；校准/锁定数据继续保持独立。

## 10月7日实际教师轨迹与参考冲突

用户授权当前助手担任教师后，已在12个训练源上生成并封存实际轨迹，见[完整结果](INTERACTIVE_TEACHER_RESULTS_20261007.md)。9例编辑、3例不修改；两种视图暂准入同一批8个文档，4例保留待审，尚无学生更新。终答投影与轨迹的比较必须固定同一终答，不能假称这是独立重新询问的direct-answer教师消融。

官方TEDS完全匹配9→10，但均值下降；一例源图分行与发布DOM合并的冲突占主要负向差异。6个原生候选字面格式标签的修复也不会完整反映在规范化指标上。这要求H4把教师自检、参考一致性和独立视觉判断拆开，并为H2的metric-only奖励保留冲突审计。当前保守过滤会偏向参考一致样本，8例中只有1例数值修正，不能据此证明过程蒸馏比终答监督更强。

## 10月9日完整表格提议与学长核验连接

[完整NF4两臂](TABLE_NF4_RESULTS_20261009.md)在首轮literal示例下无修复且各12/32保持退化；固定同checkpoint的[提示消融](TABLE_PROMPT_ABLATION_RESULTS_20261009.md)移除示例后，all只修复31/32受控重复行、不修数字/跨度，no-preservation修复更多却14/32保持退化。原生视觉提议和范围绑定仍是能力缺口，不能把受控重复行满分主张为普适修复或直接开始宣称RL收益。

[学长材料](SENIOR_CONTRIBUTIONS_20261009.md)给出候选内verdict/error/region核验监督和n1800的报告，但代码/checkpoint、原始文档隔离与完整分布确认仍缺。合理连接是固定refiner和预算，对比无诊断/真实范围/打乱范围及不同verifier的实际下游修复和风险；诊断准确率与修复分数不得直接比较。实时[共享进展页](../site/index.html)集中展示已执行、材料报告和未验证假设，后续证据追加而非替换负结果。

[同checkpoint真实原生表格诊断](NATIVE_TABLE_REPAIR_RESULTS_20261009.md)进一步限制H1/H5：两个学生0/19全修复，无部分TEDS提高；all1/13、去保持7/13原满分退化。后者32次raw修改只有16次规范化修改，不能用修改计数冒充质量增量。先检验源图使用与定位机制，再接入独立诊断，避免在没有可用提议时将RL当能力替代。

[64次白图机制探针](TABLE_SOURCE_EVIDENCE_RESULTS_20261009.md)中all27/32、去保持10/32动作与真实图条件相同；部分输出会受图像变化影响，不支持“完全不看图”的一概解释，也不证明正确视觉理解。位置/真实错误监督与独立诊断连接仍需单独验证。
