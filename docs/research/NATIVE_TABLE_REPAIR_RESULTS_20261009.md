# 原生表格学生诊断：受控重复行收益没有迁移成可靠原生纠错

2026-10-09。模型、数据、执行日志和全部评分均已保存。三组各32个真实解析器候选，共96次生成；没有重新训练，没有使用校准或锁定角色。

## 结论与适用范围

在同一批已检查的32个model-dev文章上，原生候选相对固定参考有13个TEDS满分、19个非满分。两个381-step学生checkpoint均未将任何初始非满分候选全修复，也没有任何TEDS部分提高。含保持训练模型误改1/13个原满分候选；去显式保持模型误改7/13个。受控描述式实验的31个重复行修复，不能解释为可靠原生纠错能力。

这是单seed、固定checkpoint的开发分布诊断，不是来源留出测试。公共PubTabNet数据与parser预训练可能重叠；同32篇此前被查看。满分与非满分均指发布参考和固定normalizer，不能代替独立视觉金标或语义正确判定。

## 一例真实误删：p0148-native

来源PMC2880022。源图Secondary组最后一行是Std. Deviation，体重增长0.072、身高增长0.146；原生候选保留了该行。两个学生都输出`delete_row(row=4)`，删掉真实标准差行，TEDS从1到0.821429。行号由候选DOM产生，从0计数且包括表头。这是本助手事后看源图的明确内容缺失观察，不是独立审阅者金标。

候选原TEDS=1不意味着全部视觉细节完美，例如raw转义格式标签仍可能可见。此次删除的额外缺失是源图直接支持的；我们没有用参考倒改原模型输出。此例提示“末行删除规律”可能错误泛化，但因果机制尚未证明。下一步以相同模型/文本/尺寸作真实源图与空白图对照，检验输出是否依赖有效图像证据，而非把解释当既定结论。

## 完整性核验与历史回执边界

追加CPU离线核验检查96次调用的全覆盖、源图hash、输入HTML、提示及次序，128条四臂结果、原两训练adapter的全部hash、原执行源快照和冻结阶段回执；重新计算整套TEDS/TEDS-S及汇总，与原评分对象逐字段一致。该机械核验不是另一位视觉judge。

初版生成器没有将base model receipt hash写入三份原回执。保留它们原样，后验核验确认历史controller的显式模型路径和当前模型文件与既有receipt一致；无法把缺失的历史绑定补造成当时已记录。新生成入口强制revision及receipt绑定；历史离线重放必须显式传入`--legacy-provenance`和模型receipt。此次不为补回执重跑模型、也不重写原结果。

本轮结果应促使我们先补真实错误/定位监督、检查源图使用，再验证学长verifier的诊断能否增加实际修复并降低误改。独立验收、教师学生蒸馏、RL、多seed与锁定迁移仍未完成。
